# MetroVybe

A complete Next.js starter for the MetroVybe local marketplace.

## Run

```bash
cd metrovybe
npm install
npm run dev
```

Open http://localhost:3000

## Pages

- `/` Marketplace homepage
- `/explore` Explore/map page
- `/listing/premium-pg` Listing detail example
- `/list` List a service
- `/saved` Saved
- `/profile` Profile
- `/bookings` Bookings
- `/how-it-works` How it works
- `/crm` CRM dashboard
- `/crm/customers`
- `/crm/orders`
- `/crm/listings`
- `/crm/providers`
- `/crm/payments`

This starter intentionally uses plain CSS rather than Tailwind so it is easier to run and avoids Tailwind/PostCSS configuration issues.
